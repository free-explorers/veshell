# PersistentApplicationLauncher

## Description

a PersistentApplicationLauncher is a [Tileable](tileable.md) which is used to start new application opened as [PersistentWindow](persistent_window.md) that persist in the layout even when it's closed.

## Keyboard

The launcher's search box autofocuses while the launcher is shown. Pressing
`Enter` launches the first application matching the current filter, so a search
can be accepted without reaching for the mouse (an empty result list does
nothing).
